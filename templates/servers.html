AGENT DEPLOYMENT
Linux
1. Copy agent.py to the server
2. pip install flask psutil
3. export AGENT_TOKEN=your_secret_token
4. python agent.py
   (or create a systemd service)
Windows
1. Install Python 3 (add to PATH)
2. Copy agent.py to C:\sysmon\
3. pip install flask psutil
4. set AGENT_TOKEN=your_secret_token
5. python C:\sysmon\agent.py
   (or register with NSSM)

The auth token in AGENT_TOKEN must match what you enter above.
